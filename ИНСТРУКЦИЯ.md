# TachoPlan — как пользоваться и как выложить онлайн

## Запуск на компьютере
Просто открой `index.html` двойным кликом — работает в любом браузере, данные сохраняются в этом браузере автоматически.

⚠️ Папку `fonts` держи рядом с `index.html` — в ней лежит шрифт Inter, вшитый в программу. Без неё вид «съедет» на системный шрифт.

**Светлая и тёмная тема** — кнопка с луной/солнцем справа вверху; выбор запоминается.

## Как выложить онлайн (Netlify, бесплатно, ~5 минут)
1. Зайди на **app.netlify.com/drop** (нужен бесплатный аккаунт — регистрация по email).
2. Перетащи мышкой **всю папку `D:\tachoplan`** в окно «Drag and drop your site».
3. Через несколько секунд получишь ссылку вида `https://имя.netlify.app` — её можно переименовать в настройках сайта (Site settings → Change site name), например `tachoplan.netlify.app`.
4. Эта ссылка — твоё живое демо для письма в Line Express и для собеседования.

## Как сделать «приложением» на телефоне
1. Открой свою ссылку на телефоне в Chrome.
2. Меню браузера (⋮) → **«Добавить на главный экран» / «Установить приложение»**.
3. На экране появится иконка TP — открывается на весь экран и **работает без интернета** (это PWA с офлайн-кэшем).

## Как обновлять после изменений
1. Внеси изменения в файлы (или попроси Claude Code).
2. В файле `sw.js` подними версию в строке `const CACHE = "tachoplan-v3.0.0"` (например на `v3.0.1`) — так телефоны узнают об обновлении.
3. Снова перетащи папку на Netlify (Deploys → Drag and drop) — ссылка останется той же.

## Важно про данные
Все машины и туры хранятся **в браузере устройства** (localStorage). Телефон и компьютер друг с другом не синхронизируются. Перенести данные между устройствами можно через **Export CSV → Import**.

## Демо-режим (для показа рекрутеру и на собеседовании)
Добавь к ссылке `?demo` — борд сам заполнится флотом из 8 машин с недельной историей водителей, при этом твои настоящие данные не тронутся и ничего не сохранится.
Можно открыть сразу нужное: `?demo&open=TRK-04&q=karl` — одна машина с раскрытым редактором, `?demo&view=drivers` — аналитика по водителям.

## Формат CSV для импорта
Смотри пример в файле `example_tours.csv` — его можно открыть в Excel, поправить и вставить в окно Import прямо копипастом (Ctrl+C из Excel → Ctrl+V в поле Import).
