The full licence text is in OFL.txt in this folder, as the licence requires when
the font is redistributed.

These are the variable woff2 subsets (latin, latin-ext, cyrillic, cyrillic-ext)
as served by Google Fonts, bundled locally so the planner renders identically
offline and on machines where Inter is not installed. Each file covers the full
weight range 100-900, which is why there is one file per character subset rather
than one per weight.
